# Ink Press

Публичная лента материалов + админка на **Next.js (App Router) + React 19 + TypeScript**.  
Второй учебный пет после [Signal Shelf](https://github.com/Gh0st0fwAr/signal-shelf): повторяем React-паттерны и заходим в Next.

## Цель

- Публичка: лента, теги, поиск, страница поста  
- Админка: CRUD, черновик / опубликовано, простой логин (учебный)  
- Next: layouts, Server/Client Components, route groups, loading/error  

Чеклист шагов: [LEARNING.md](./LEARNING.md) · карта: [ГАЙД.md](./ГАЙД.md)

## Стек

- Next.js 16 (App Router)
- React 19 + TypeScript
- SCSS (design tokens)
- дальше по шагам: RHF, TanStack Query (где уместно), Context UI prefs

## Dev

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).
